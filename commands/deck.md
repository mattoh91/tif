---
description: "Render an opt-in Gummy slide deck"
---

Use `gummy:documentation` in deck mode. Synthesize the deck content model from `.gummy/` artifacts, render a self-contained `docs/ppt/deck.html` with `gummy:ui-ux-pro-max` styling, and run the diagram neatness gate before reporting the deck as accepted. The deck is opt-in: only `/deck` generates it. Never claim the diagram is verified if the neatness gate was skipped.
