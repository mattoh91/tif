# Snake Game Product Requirements

## Goal

Provide a tiny browser-playable Snake game fixture for testing Sweet's feature/component gate workflow inside the repository.

## Users

- Sweet harness maintainers validating planning, implementation, gate, and state-update behavior.

## Features

- F1: Play Snake in a browser using keyboard controls.
- F2: Verify core game behavior through an automated dependency-free test gate.

## Non-Goals

- No persistent leaderboard.
- No mobile touch controls.
- No external runtime dependencies.
